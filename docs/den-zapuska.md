## Куда переезжаем (слово фаундера 20.09.2026)

**Яндекс Облако, по образу и подобию айчека** — не GitHub Pages и не Vercel.
Образец рабочий и живёт третий год, поэтому переписывать архитектуру не надо,
надо повторить:

| Слой | Как у айчека | Что это значит для Фионики |
|---|---|---|
| Статика | Object Storage + Yandex CDN | наши страницы и приложение — те же файлы, просто в бакете |
| DNS | reg.ru, A-запись на edge CDN | у нас пока нет домена вовсе (§ «фаундер», шаг 3) |
| TLS | Let's Encrypt через Yandex Certificate Manager, авто-продление | ⚠️ у айчека сертификат выписан только на голое имя, и `www.` даёт ошибку DNS — у нас сразу выписывать на оба |
| Выкладка | GitHub Actions на push в `main` → `aws s3 sync` → CDN | у нас сборки нет: `npm run build` только собирает однофайловую копию, класть в бакет надо сам репозиторий |
| Заголовки | CDN `static_headers` (HSTS, X-Content-Type-Options и прочие) | правятся в облаке, в репозитории их нет |
| Прогресс учеников | — | остаётся там, где есть: Cloud Function + Object Storage, уже в РФ |
| Оплата | Cloud Function → ЮKassa → вебхук → **очередь** → чек НПД в «Мой налог» | у нас этого нет вовсе; повторяем схему целиком, включая очередь |

⚠️ **Три грабли айчека, которые у нас будут те же, и лучше знать заранее:**

1. **Кеш CDN не лечится `purge --all`, если менялся только заголовок.**
   Содержимое то же → ETag тот же → узел отвечает `304` и оставляет свой
   прежний `Cache-Control`. Проверять по `cache-status` в ответе.
2. **У нас 50+ файлов `js/*.js` без хеша в имени** (замер 20.09.2026: загрузка
   приложения — 137 запросов). Длинный кеш на них означает, что правка урока
   не доедет до ребёнка неделю. Значит: HTML и `js/` — короткий кеш с
   ревалидацией, шрифты и картинки — длинный. ⚠️ Отдельно и жёстко: **`sw.js`
   длинным кешем не отдавать никогда** — это оболочка офлайна, она решает,
   какую версию видит человек без сети.
3. **Чек НПД пробивать не в вебхуке, а через очередь.** У айчека это стоило
   инцидента: ФНС отвечает 20+ секунд, ЮKassa рвёт соединение по таймауту.

## Приёмка дня

Готовность считается из репозитория, а не из памяти:

```
node tools/zapusk.js
```

Отчёт называет версию, размер сборки и запас до потолка, все файлы с прошитым
адресом, все места про цену, наличие `CNAME`, правовых страниц и признаков
оплаты в коде. Пока в строке «замок по оплате» стоит «нет», продавать
подписку нечем, чем бы ни был настроен ЮKassa.
