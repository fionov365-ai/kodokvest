Как это устроено

Ничего не устанавливать, ничего о ребёнке не спрашивать.

Браузер и офлайн

Обычная страница на любой машине. Ставится иконкой на домашний экран и работает без интернета, а для класса есть сборка одним файлом.

Без персональных данных

Ни почты, ни телефона, ни фамилии: прогресс живёт под коротким кодом ученика, имя остаётся на устройстве. Карточку доступа тренажёр печатает сам.

Свой интерпретатор

Python выполняется прямо в браузере, без сервера. Каждый пример курса при сборке сверяется с настоящим python3.

Мелочи, которые заметны

Шпаргалка команд поверх любого экрана, поиск по урокам, чтение урока вслух, тёмная тема и наборы оформления, ревью кода и возврат трудных уроков.

Честно про границы

  • Язык программирования один — Python, тот же, что в ЕГЭ. HTML и CSS — разметка для страниц, а не второй язык: они ничего не вычисляют.
  • Из информатики закрыто программирование и задачи экзамена, а не предмет целиком. Электронные таблицы судить нечем: наш судья запускает Python, а не считает формулы.
  • Проверяет программа, а не человек. Живого преподавателя здесь нет.
  • Мы не образовательная организация: не аттестуем и не выдаём документов об образовании.
  • Аккаунта нет — есть код ученика. По утраченному коду восстановить прогресс сейчас нельзя.
