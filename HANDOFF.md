# ЧТО УЖЕ СДЕЛАНО

**Готово 60 уроков из 100: Миры 1, 2 и 3 целиком.**

**Движок** (`js/engine-mini.js`, мини-Python на JavaScript, ~2400 строк) умеет:
переменные, int/float, строки и f-строки с полным форматом (`{x:8}`, `{x:.2f}`,
`{x:02d}`, `{x:*^9}`, `{n:,}`, `{x!r}`), списки, словари, кортежи, множества,
срезы, `if/elif/else`, `for`, `while`, `break/continue`, `def` со значениями по
умолчанию, `*args`/`**kwargs` и распаковку `f(*список)`/`f(**словарь)`, `lambda`,
включения всех видов, цепочки сравнений, `sorted(key=...)`, `max/min` с `key=`,
`try/except/else/finally`, `raise`, `assert`, свои классы исключений, полную
иерархию исключений, **классы** (`__init__`, `self`, методы, поля класса и
объекта, `__repr__`, `__str__`, `__eq__`, наследование, `super()`, `isinstance`),
честный `type()` (`<class 'int'>`), `import` своих модулей и `math`/`random`/
`dataclasses`, применение декораторов, `@dataclass`, около 60 встроенных функций,
методы строк, списков, словарей и множеств, черепашью графику.
Ошибки по-русски с номером строки, у встроенных ошибок `str(e)` даёт ровно
питоновский английский текст. Защита от вечных циклов и от бесконечной рекурсии.
Пошаговое выполнение через генераторы.

**Чего движок пока НЕ умеет** (это работа Мира 4 и Pyodide):
генераторы (`yield`), написание своих декораторов, `with`, работа с файлами,
почти вся стандартная библиотека, целые числа больше 2^53 (это JavaScript).

**Слой Runtime** (`js/runtime.js`): работает адаптер `mini`, адаптер `pyodide` —
честная заглушка, которая отвечает «не подключено».

**Сервер прогресса** — работает. Yandex Cloud, каталог `kodokvest`:
Cloud Function `kodokvest-progress` (`d4eog8isvkbphfav8n76`) плюс приватный бакет
`kodokvest-progress-7f3a91`, смонтированный к функции как папка
`/function/storage/progress`. Адрес прописан в `js/cloud-config.js`.
Прогресс не перезаписывается, а **сливается**: по каждому уроку берётся лучший
результат из двух копий. Код ученика — настройка устройства (`?kid=код` или поле
в панели), в файлах сайта его нет.

**Панель наставника**: сводка, таблица всех 100 уроков со статистикой, открыть/
зачесть/сбросить урок, снятие замков, XP и бейджи, просмотр прогресса другого
ученика по коду, список всех учеников по ключу наставника, перенос прогресса файлом.

**Механики заданий**: `code` (написать по заготовке), `fix` (найти и починить
ошибку), задание **из нескольких файлов** (вкладки над редактором, `import`
между файлами работает) и проверка **скрытыми тестами** (`check.kind = "tests"`).
Зарезервированы, но не сделаны: `blocks` (собрать из перемешанных строк),
`predict` (угадать вывод).

**Пять наборов тестов**, все зелёные, запускаются одной командой `npm test`:
1. `tests/engine-vs-python.js` — 108 программ через `python3` и через движок, вывод совпадает символ в символ
2. `tests/lessons.js` — решения, заготовки, примеры, схема всех уроков
3. `tests/content-vs-python.js` — 313 сверок: каждый пример и каждое решение из всех уроков против настоящего python3, включая многофайловые уроки и скрытые тесты
4. `tests/cloud-function.js` — серверная функция на временной папке вместо бакета
5. `tests/full-run.js` — вся игра в jsdom: решения засчитываются, заготовки нет, обходные пути в «починке» отклоняются, ноль ошибок JS

Плюс служебный `tests/try-one.js файл.py` — сверить одну программу вручную,
в `npm test` не входит.

# ЧТО СДЕЛАНО В ПОСЛЕДНЮЮ СЕССИЮ (Мир 3)

Порядок был обратный привычному: сначала движок, потом уроки.

Добавлено в движок: `*args`/`**kwargs`, однократное вычисление значений по
умолчанию, `try/except/else/finally`, `raise`, `assert`, иерархия исключений,
классы с наследованием и `super()`, честный `type()`, `import`, декораторы,
`@dataclass`, `UnboundLocalError` (Python решает вопрос местных переменных
до запуска — теперь и движок тоже), полный разбор формата в f-строках.

Заодно исправлены четыре расхождения с настоящим Python, которые нашлись
по ходу и попали бы прямо в урок:

1. `"абв".isalpha()` возвращал `False` — в JavaScript `\w` это только латиница.
2. `{x:02d}` печатал `« 5»` вместо `«05»` — заполнение нулями не поддерживалось.
3. `round(2.5)` давал 3, а Python даёт 2: он округляет половинки к ближайшему
   чётному. Считать через умножение на 10^n нельзя — разбираем десятичную запись.
4. `return a, b` без скобок вообще не разбирался.

Все четыре закрыты программами в корпусе сверки.

# ЗАДАЧА НА СЛЕДУЮЩУЮ СЕССИЮ: МИР 4 «НАСТОЯЩИЙ PYTHON»

Двадцать уроков, id уже заведены в `js/curriculum.js`:
imports, math-random, datetime, files-read, files-write, pathlib, json, csv,
collections, itertools, generators, decorators, context, regex, typing,
pip-venv, read-code, pep8, perf, boss-tool.

Начиная с `generators` уроки помечены `engine:"pyodide"` — предполагается
настоящий CPython в браузере. Главное решение сессии: подключать Pyodide
по-настоящему (около 10 МБ, папка `vendor/pyodide/`, переписать адаптер в
`js/runtime.js`) или дотягивать мини-движок. Оба пути честные, но разные по цене:
Pyodide даёт всю стандартную библиотеку и снимает ограничение на большие числа,
зато сайт перестаёт открываться из одного файла и грузится дольше.

Первые уроки мира (`imports`, `math-random`) на текущем движке уже пишутся:
`import math`, `random`, свои модули — всё есть. Для `datetime`, `json`, `csv`,
`collections`, `itertools` нужны либо новые встроенные модули в мини-движке,
либо Pyodide. Работа с файлами (`files-read`, `files-write`, `pathlib`) в
браузере требует придуманной файловой системы — так же, как в Мире 3 придуманы
файлы урока для `import`.

# ГРАБЛИ, НА КОТОРЫЕ УЖЕ НАСТУПАЛИ

Прочитай это до начала работы — сэкономит полсессии.

1. **Порядок элементов множества совпасть не может.** Настоящий Python выдаёт
   разный порядок при каждом запуске программы. Правило проекта: множество
   печатается только через `sorted()`. В корпус сверки такие случаи не добавлять.
2. **`build.js` собирает «голову» страницы из `index.html`.** Не собирай файл
   без `<meta charset="utf-8">` — при открытии с диска весь русский текст
   превращается в «РљРѕРґРѕРєРІРµСЃС‚». В `tests/full-run.js` на это есть проверка
   по байтам, не убирай её.
3. **Проверяй тот файл, который открывает человек.** Один раз тест сам оборачивал
   сборку в правильный документ и поэтому пропустил поломку кодировки.
4. **Сортировка в Python устойчивая.** `reverse=True` — это смена знака сравнения,
   а не переворот готового массива, иначе равные элементы меняются местами.
5. **Формат в f-строке отделяется двоеточием только на верхнем уровне.**
   Внутри скобок это срез (`s[1:3]`), внутри кавычек — просто символ.
   Выравнивание по умолчанию зависит от типа: числа вправо, текст влево.
6. **У заданий `fix` есть бюджет правок** (`fixBudget`, по умолчанию — разница
   между заготовкой и решением плюс одна строка). Если у задания есть короткий
   обходной путь, поставь бюджет вручную **и добавь этот путь в список `BYPASS`
   в `tests/full-run.js`** — тест требует хотя бы один обходной путь на каждое
   задание `fix` и проверяет, что защита его отклоняет.
7. **Задания со случайностью нельзя проверять сравнением вывода.** Для них есть
   `check: { kind: "custom", fn: "..." }` — функции в объекте `CUSTOM` в `app.js`.
8. **Порядок уроков — это ограничение.** В уроке можно использовать только то,
   что объяснено раньше по программе. Например в Мире 3 урок `class-first` идёт
   раньше урока про `__init__`, поэтому поля там задаются снаружи через точку —
   и это честно работает.
9. **`id` уроков менять нельзя** — по ним хранится прогресс в localStorage и на
   сервере.
10. **Печатать функцию или объект без `__repr__` нельзя.** Настоящий Python
    показывает адрес в памяти (`<function double at 0x7f…>`), повторить его
    невозможно. В уроках печатаем `type(x)` либо задаём `__repr__`.
11. **Целые числа больше 2^53 считаются неточно** — это JavaScript. Поэтому
    `math.factorial` отказывается работать выше 20!, а в уроках про рекурсию
    большие факториалы не используются.
12. **Заготовка обычного задания обязана запускаться.** Проверь мысленно: ребёнок
    открыл урок, нажал «Запустить» — он должен увидеть работающую, пусть и
    неправильную, программу, а не красную ошибку. Тест `lessons.js` это ловит,
    и в этой сессии он поймал три таких заготовки.
13. **Голое `except:` в уроках не показывать как рабочий приём** — оно проглатывает
    и опечатки. Защита тренажёра от вечного цикла помечена как неперехватываемая,
    так что обойти её через `try` нельзя.
